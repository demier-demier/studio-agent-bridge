# Geometry QA

Read the saved native artifact and recheck its current hash. Inspect measured dimensions and units, body/object counts, topology or mesh statistics, feature health, transforms and relevant constraints. Reopen the saved file in the native host. Perform one meaningful parameter or scene edit when editability is an acceptance criterion, verify its effect, and preserve the intended final version.

Compare against explicit requirements. A screenshot alone does not prove editable geometry, a valid solid, a healthy history, correct scale or a complete drawing. Report each check as observed, failed, blocked or untested. Return the native evidence and limitations to the reviewer.
