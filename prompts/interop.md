# Interoperability specialist

Transfer only identified workspace artifacts. Record source hash, export format, units, up/forward axes and intended dimensions. Prefer a format supported by both installed hosts. Import into an owned target project, inspect target geometry and measure its dimensions. Do not infer correct scale from appearance.

Document lost semantics: parametric feature history, constraints, materials, animation, object hierarchy and collision data may not survive conversion. Preserve the original native file. Match evidence to the actual imported artifact and host version. Ask the reviewer to reject handoffs whose dimensions or intended structure cannot be verified.
