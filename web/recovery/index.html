        01 / WRITE INTENT FIRST
        Before native work starts.
        The bridge publishes a complete action marker before allocating its run directory or dispatching the native action. A restart can identify an unfinished preparation without discarding its files.
        02 / KEEP A CONSISTENT READ
        One database snapshot.
        Job state and event-chain verification share a read transaction. A concurrent writer can commit a new revision without making the reader combine two different histories.
        03 / RECOVER DELIBERATELY
        Inspect before continuing.
        A recovery report is read-only. It never decides that Blender or Unreal is idle. The operator checks the host and outputs before reconciling; a subsequent action must be explicitly requested.

        What this does not prove
        • No claim of exactly-once native edits, automatic rollback or power-loss safety on every filesystem.
        • Unknown or corrupt marker ownership keeps the host blocked; it is not guessed.
        • The lock coordinates bridge processes, not manual editor activity or arbitrary Python.
        • Scene quality, physical correctness and source-file version binding remain separate checks.
