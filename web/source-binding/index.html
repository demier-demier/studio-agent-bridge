A VERSION IS MORE THAN A FILENAME

The edit starts from
a reviewed scene.

The client provides a trusted edit script and the hash of the scene it inspected. If the file changed, the bridge refuses the stale request before starting Blender.

For a matching source, the bridge creates a read-only snapshot and checks the bytes actually copied. Blender edits from that snapshot, saves a separate native scene, and reopens the result. The original and snapshot are checked again afterward.

Read-only permissions help prevent accidental writes. Privileged scripts are not sandboxed, and file hashes do not establish artistic or engineering correctness.
